# Sitemap, SEO & New Features — Keep Track

Single reference for what drives the sitemap and SEO, and what to update when you add new features. **Update this doc when you add routes, lists, blog posts, or guides.**

---

## 1. Sitemap (public/sitemap.xml)

Generated by **`scripts/generate-sitemap.js`** at build time (`npm run build`). Base URL: `process.env.SITE_URL || "https://mosquelist.com"`.

### What’s included (in order)

| Source | URLs | How it’s added |
|--------|------|----------------|
| **Static routes** | `/`, `/explore`, `/map`, `/lists`, `/timeline`, `/islamic-history`, `/bucket-list`, `/about`, `/glossary`, `/contributing`, `/guides/travel`, `/guides/visitor-tips`, `/blog` | Hardcoded in `generate-sitemap.js` |
| **Blog posts** | `/blog/{slug}` | Slugs extracted from `src/data/blog.ts` (regex on `slug: "..."`) |
| **Lists** | `/lists/{slug}` | From `src/data/lists.json` → `lists[].slug` |
| **Mosques** | `/mosque/{id}` | From `src/data/mosques.json` → `mosques[].id` |

### When you add…

- **A new static page (e.g. new guide or section):**  
  1. Add route in `src/App.tsx`.  
  2. Add URL in `scripts/generate-sitemap.js` in the `urls` array (same order as above).  
  3. Add to **Key pages** in `public/ai.txt` (see below).

- **A new blog post:**  
  Add the post in `src/data/blog.ts`. Sitemap picks up new slugs automatically.

- **A new list:**  
  Add the list in `src/data/lists.json`. Sitemap picks up new list slugs automatically.

- **New mosques:**  
  Add in `src/data/mosques.json`. Sitemap picks up new mosque IDs automatically.

## 2. SEO touchpoints

| Touchpoint | Where | When to update |
|------------|--------|----------------|
| **Homepage meta & OG/Twitter** | `index.html` | Product copy or scale change (e.g. mosque/country counts). |
| **Canonical (home)** | `index.html` | Only if production URL changes. |
| **JSON-LD (WebSite)** | `index.html` | If search URL or site description changes. |
| **Per-page title/description/canonical** | `PageSEO` in each page component | When adding a new page or changing that page’s purpose. |
| **JSON-LD (Place, ItemList, BlogPosting)** | Mosque page, list page, blog post page components | When schema or fields change. |
| **robots.txt** | `public/robots.txt` | If you change sitemap URL or crawler rules. |
| **ai.txt** | `public/ai.txt` | When you add a new section, guide, or key page; keep “Key pages” and “What this site offers” in sync. |

## 3. Guides and key pages

| Page | Path | SEO (PageSEO) | In sitemap | In ai.txt |
|------|------|----------------|------------|-----------|
| Travel guide | `/guides/travel` | Yes | Yes | Yes |
| Visitor tips | `/guides/visitor-tips` | Yes | Yes | Yes |
| Glossary | `/glossary` | Yes | Yes | Yes |
| Contributing | `/contributing` | Yes | Yes | Yes |
| About | `/about` | Yes | Yes | Yes |

When you add a **new guide** (e.g. `/guides/xyz`): add route in App, add URL in sitemap script, add to ai.txt “Key pages” and “Guides” (or equivalent) in “What this site offers.”

## 4. Curated lists (for ai.txt & content)

Lists live in **`src/data/lists.json`**. Sitemap includes all `lists[].slug` automatically. For discoverability and AI/indexing, keep **ai.txt** “Curated lists” line in sync with notable lists (e.g. Holy Sites, Biggest Mosques, Shia Mosques, Shia Shrines, by country, by era).

Current notable lists (examples): `holy-sites`, `biggest-mosques`, `shia-shrines`, `shia-mosques`, by-century, by-country, by-style, UNESCO, tourist-friendly, etc. No need to list every slug in ai.txt—a short phrase is enough (“Holy Sites, biggest mosques, Shia mosques & shrines, by country, by era and style”).

## 5. Quick checklist: “I added something new”

- [ ] **New route (e.g. new page):** App.tsx + `generate-sitemap.js` + ai.txt “Key pages” (and “What this site offers” if it’s a new section like a guide).
- [ ] **New blog post:** Entry in `src/data/blog.ts` only (sitemap auto).
- [ ] **New list:** Entry in `src/data/lists.json` only (sitemap auto). Optionally mention in ai.txt if it’s a major list.
- [ ] **New mosque(s):** Entry in `src/data/mosques.json` only (sitemap auto).
- [ ] **Copy/scale change (e.g. 199+ mosques):** index.html meta/og/twitter; PageSEO/ListSEO/MosqueSEO fallbacks; guides (Travel, Visitor tips), About, Index, Explore, Lists, Timeline; Footer; BucketList; blog.ts; README; marketing. Search codebase for the old number (e.g. `100+`) to find remaining refs.
