## How to use this list

1. **Pick a country** from the table/sections above (start with Central Asia or high-population African countries if prioritising coverage).
2. **Within countries already in the app,** use the "Major states, provinces & cities" section to add **large**, **city-center**, or **historic** mosques in key cities.
3. **Verify mosque names and facts** using Wikipedia, official/government tourism sites, and Encyclopaedia of Islam or Britannica where possible.
4. **Use the schema** in `docs/mosque-data-prompt.md` and existing entries in `src/data/mosques.json` to build full JSON objects (id, name, location, country, capacity, established, imageUrl, significance, description, etc.).
5. **Prefer images** from Wikimedia Commons (direct `upload.wikimedia.org` URLs) or other clearly licensed sources; note any gaps in `docs/mosque-data-gaps.md`.
6. **Add one or two mosques per country** first (e.g. the main national or most iconic mosque), then expand by city/region.
